# Практическая работа #4
Изучение работы в системе контроля версий
## Инструкция по установке
Cклонировать этот репозиторий
```sh
git clone https://github.com/70P6YH08/Lab4
```
И запустите .sinx файл проекта
## Использование
Использование проекта может быть в ознакомительных целях
##Системные требования
- оперативная память от 512 Мб
- свободное дисковое пространство от 200 Мб
- visual studio с поддержкой версий .net 10
